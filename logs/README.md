# Project Logs

This folder contains logs of all development work, problems solved, and ongoing issues.

## Log Files

| File | Purpose |
|------|---------|
| `WORK_COMPLETED.md` | Log of all completed tasks with dates |
| `PROBLEMS_SOLVED.md` | Log of issues encountered and how they were resolved |
| `KNOWN_ISSUES.md` | Current known issues and blockers |
| `CHANGELOG.md` | Version-based changelog of features and fixes |

## For AI Agents

**IMPORTANT RULE**: After completing any task:
1. Update `WORK_COMPLETED.md` with what was done
2. If a problem was solved, add it to `PROBLEMS_SOLVED.md`
3. Update `KNOWN_ISSUES.md` if any issues were discovered or resolved
4. Update `../PROJECT_CONTEXT.md` with the current state

This ensures continuity between AI agent sessions and provides a clear audit trail.
